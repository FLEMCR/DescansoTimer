Es un cronometro de descanso que cada cierto intervalo (por defecto: 1 hora) muestre una ventana con un botón que al presionar ejecute un segundo cronometro (por defecto: 5 minutos) para poder descansar, estirarse, etc., en ese tiempo (AFK) y después de ese tiempo aparecerá otra ventana pra asi continuar con otro cronometro (por defecto: 1 hora) y asi repetirse en bucle.

La elaboración de este mini proyecto fue hecha con ayuda de la IA a modo de instructor para aprender el como elaborar un proyecto de este estilo puesto que no soy experto en el tema.

El objetivo es evitar estar mucho tiempo de corrido usando la computadora y tener un momento para romper rutina.
